# EV Charging Infrastructure and Sales Analysis

Python project analyzing annual electric vehicle (EV) sales and charging infrastructure trends in the United States.

## Objective

Analyze EV market growth by:

- calculating total EV sales in 2018
- comparing trends in private and public charging ports with EV sales
- examining relationships between charging infrastructure and vehicle sales from 2015 to 2018

The analysis uses aggregated annual data on private charging ports, public charging ports, station locations, and EV model sales.

## Files
- notebook.ipynb - project notebook with data analysis and visualizations
- private_ev_charging.csv - annual private EV charging infrastructure data
- public_ev_charging.csv - annual public EV charging infrastructure data
- ev_sales.csv - annual EV sales by vehicle model
- solution.py - final Python script with the complete analysis
