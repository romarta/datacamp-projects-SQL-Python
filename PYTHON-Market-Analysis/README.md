# Fitness Trends Analysis

Python project analyzing Google Trends data to understand the popularity of workout-related search terms and digital fitness trends worldwide.

## Objective

Analyze fitness search trends to:

- identify the year with the highest interest in the term workout
- compare the popularity of home workout, gym workout, and home gym
- examine changes in interest during the COVID-19 period and in 2023
- analyze workout-related interest across countries

The analysis uses Google Trends popularity indexes ranging from 0 to 100.

## Files
- notebook.ipynb - project notebook with the Python analysis
- data/ - CSV files containing worldwide and country-level Google Trends data
- solution.py - final Python script with the complete analysis
