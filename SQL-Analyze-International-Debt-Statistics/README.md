SQL project analyzing international debt data collected by the World Bank
for developing countries.

## Objective

Analyze international debt by:
- number of distinct countries
- country with the highest total debt
- country with the lowest principal repayment

Debt values are measured in current US dollars across different debt indicators.

## Files

- `notebook.ipynb` - project notebook with the SQL solution
- `image.jpg` - image used in the project notebook
- `solution.sql` - final SQL query
