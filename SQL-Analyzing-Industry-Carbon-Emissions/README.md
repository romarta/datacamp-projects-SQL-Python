# Product Carbon Footprint Analysis

SQL project analyzing product carbon footprints across different industry groups
using data from the most recent year available in the dataset.

## Objective

Analyze carbon emissions by:

- industry group
- number of companies
- total industry carbon footprint

The analysis uses the latest available year and calculates the total product
carbon footprint for each industry group.

## Files
- `notebook.ipynb` - project notebook with the SQL solution
- `pollution.jpg` - image used in the project notebook
